§ 02

What it is

— 02 / 04 —

A full-size humanoid for people who want to understand, repair and change their own robot. If you can run a printer and a screwdriver, you can build one.

4 principles — 1 : 1
A.01Printable

Printed structure

Limbs, torso and head are designed for common desktop printers, so a build costs a fraction of a commercial humanoid.

Build guides
A.02Open

Everything public

CAD, firmware, wiring and the bill of materials are published as they’re finished, with the reasoning behind each choice.

Read the log
A.03G1-based

Built on the Unitree G1

We follow the G1’s proportions and joint layout, so existing humanoid research and control code can carry over.

Design notes
A.04Buildable

Part-by-part tutorials

Each part gets its own guide with files, print settings, hardware list and assembly steps, so you can build one piece at a time.

Start a part
